<h1 align="center">Explorer's Dynamic Offhand Map</h1>

This is the Explorer's Dynamic Offhand Map repository, welcome.

Explorer's Dynamic Offhand Map Mod is a [Minecraft](https://minecraft.net/) Java Mod centered around exploring the Minecraft World with an immersive map.
Immersion is experienced through the use of a Camera-based Fog-of-Discovery HUD to track only what the player has looked at in the Minecraft World.
The Explorer's Dynamic Offhand Map Mod is inspired by Minimap Mods  such as [Xaero's Minimap](https://www.curseforge.com/minecraft/mc-mods/xaeros-minimap) and [JourneyMap](https://www.curseforge.com/minecraft/mc-mods/journeymap) but with a twist.
